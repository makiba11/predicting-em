# Experiment configuration

- `em_experiment.json` is the main Qwen3-8B experiment config.
- `model_screening/config.json` and `model_screening/pricing.json` configure
  the exploratory model screen. Its commands are in
  [model_screening/README.md](model_screening/README.md).

Saved run configs and immutable evaluation manifests are under `artifacts/`.
See [EVALS.md](../EVALS.md) for the current run inventory and results.
